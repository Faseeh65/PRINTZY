# SEO launch checklist

## Before launch

- [ ] Confirm the canonical hostname and HTTPS redirect for `printzy.site`.
- [ ] Verify Search Console and Bing Webmaster Tools ownership.
- [ ] Compare `public/sitemap.xml` against canonical, indexable routes; exclude utility pages and add accurate `lastmod` only when content changes.
- [ ] Submit the sitemap in Google Search Console and Bing Webmaster Tools.
- [ ] Check `public/robots.txt` and verify that CSS, JavaScript, and image assets remain crawlable.
- [ ] Review every title, meta description, H1, canonical URL, and Open Graph image for uniqueness and accuracy.
- [ ] Validate JSON-LD against the visible content on every page template. Do not publish offers, reviews, locations, hours, or credentials unless they are real and visible.
- [ ] Run a broken-link and redirect-chain crawl; check for orphan pages.
- [ ] Verify image alt text, dimensions, responsive variants, and below-the-fold loading behavior.
- [ ] Measure mobile Lighthouse performance, accessibility, SEO, and best-practices on home, product, blog, and quote pages.
- [ ] Test layouts and fixed CTA clearance at 360px and 390px widths, with keyboard navigation and reduced motion.
- [ ] Submit a quote end to end; confirm storage, owner email delivery, spam protection, file validation, thank-you state, and conversion event.
- [ ] Confirm WhatsApp, phone, sample, and other conversion events reach the GTM data layer. Keep the existing container ID `GTM-W8JX29CJ` unchanged.

## Search Console and Bing

- [ ] Submit the verified XML sitemap.
- [ ] Inspect the home page and representative product, industry, city, blog, policy, and conversion URLs.
- [ ] Review indexing, canonical selection, crawl errors, and structured-data reports.
- [ ] Confirm mobile rendering and key page content with URL inspection tools.

## First 30 days

- Review indexing and crawl errors weekly.
- Track impressions, clicks, non-branded query growth, quote submissions, WhatsApp clicks, calls, and sample requests.
- Compare conversion rates by landing page and device; fix form errors and mobile CTA overlap first.
- Update `dateModified` only when article content is materially updated.
- Add new photos, testimonials, case studies, or compliance documents only after owner verification and permission.
